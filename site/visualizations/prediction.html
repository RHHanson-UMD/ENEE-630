LINEAR PREDICTION / ORIGINAL EXAMPLE

Predict forward or backward. Check what changes.

Explore optimal one-sided linear prediction for a zero-mean, stationary Gaussian AR(1) process with covariance r[k] = σ²ρ|k|. The model is deliberately simple: it demonstrates how prediction direction and order relate to error orthogonality without using instructor problem parameters.

Which samples matter?

Samples in violet are observed regressors. The target at time 0 is highlighted; other timeline samples are not used. Read the optimal coefficients in order from nearest to farthest.

Why is the error orthogonal?

X̂[0] = Σj=1M aj X[±j],   e = X[0] − X̂[0]

Under this stationary Gaussian AR(1) model, the nearest neighbor is sufficient for one-sided prediction. For M ≥ 1, the optimal coefficient vector is [ρ, 0, …, 0]. For M = 0, the prediction is zero and the MSE equals σ².

For M ≥ 1: Var(e) = σ²(1 − ρ²);   Cov(e, X[±j]) = r[j] − ρr[j−1] = 0.

What does this example not establish?

For a general stationary process, extra observed lags can improve prediction and forward/backward coefficient vectors need not match. The AR(1) Gaussian Markov structure gives the special simplification above. |ρ| ≥ 1 is outside this stationary covariance example. An observed neighboring value is not the true target, so the conditional mean is a prediction, not an exact observed X[0].
